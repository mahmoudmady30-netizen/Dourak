# Dourak V54 — Feature Audit

- Display controls moved out of the independent TV/display page and into the owner dashboard under Queue Display settings.
- Five radically different display systems: Aurora, Editorial, Neon, Luxe, Terminal.
- Owner-controlled display zoom (85%–118%) is stored on the business and applied to the independent display.
- Promotion hard-lock remains available; disabled promotions are explicitly hidden and cleared from the rendered banner.
- Customer log is grouped by month, shows the latest 20 unique customers, supports Load More, search by name/phone, day/month filters, and an expandable visit history popup.
- Phone matching accepts numbers with or without a country code and stores normalized variants for walk-in lookup.
- Walk-in flow now asks for phone + name and auto-fills a known customer's name when a matching phone is found.
- Every business gets a globally unique human-shareable `DRK-XXXXXXX` code; the code is shown on the owner home page and can be used by customers for direct business lookup.
- Existing V51/V52 audio, realtime queue, fullscreen, fit-to-screen, functions, rules, tests, and assets are preserved.
