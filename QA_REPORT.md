**Scope:** full web/PWA app (`index.html`, `firestore.rules`, `sw.js`, `manifest.json`).
**Method:** static analysis · unit tests · UI smoke across all roles · responsive (320/375/768/1280) ·
accessibility · security (XSS sinks + Firestore rules audit) · regression of all earlier suites.
**Environment:** headless Chromium + Node. No real devices, no live Firebase, no Firestore emulator.
